# 📘 Fundamentos de HTML e CSS

Este repositório reúne meu aprendizado prático e teórico dos fundamentos do HTML e do CSS 
tecnologias base da construção de páginas web. 
Por meio de exercícios e pequenos projetos, consolidei os conceitos essenciais para estruturar e
estilizar interfaces responsivas, limpas e funcionais.

---

## 🧠 O que aprendi

- Estruturação de páginas com HTML semântico
- Manipulação de textos, listas, imagens, links, tabelas e mídias
- Criação e validação de formulários
- Inclusão de caracteres especiais e recursos multimídia
- Conceito de **Box Model**: controle total de espaçamentos com `margin`, `padding`, `border` e `content`
- Aplicação de estilos com CSS externo, interno e inline
- Uso de `div` e `span` para agrupamento e estilização de elementos
- Manipulação de fontes, cores, alinhamentos e imagens de fundo
- Unidades de medida absolutas e relativas (`px`, `em`, `rem`, `%`, `vh`, `vw`)
- Seletores CSS básicos, combinadores, pseudo-classes e pseudo-elementos
- Herança, cascata e especificidade nos estilos

---

## 💻 Projetos desenvolvidos

Durante os estudos, realizei pequenos projetos e exercícios práticos que reforçaram os conceitos aprendidos:

- **Formulário de Contato:** formulário completo com campos de texto, seletores, caixa de mensagem e botão de envio estilizado.
- **Página de Produtos:** layout responsivo de uma página com cards de produtos, imagens, descrições e organização em colunas com `flexbox` (inicial).
- **Perfil Pessoal Simples:** estruturação de uma página com foto, descrição, links e estilização básica.
- **Exercício de Cores e Imagens de Fundo:** aplicação prática de gradientes, imagens de fundo e sobreposição com transparência.
- **Mini landing page:** pequena página de apresentação com foco em hierarquia visual e organização do conteúdo.


## 🛠️ Tecnologias utilizadas
